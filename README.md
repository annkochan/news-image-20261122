One 1024x1024 image summarising the world news of Sunday, 22 November 2026:

- Lead: COP31 climate talks in Antalya, Turkiye, collapse with no deal
- Libya: suspected Ukrainian sea drones hit a Russian warship at Benghazi
- Gulf: ships hit near Hormuz; Bahrain industrial site ablaze
- USA: Agriculture Department and FBI systems breached
- Trade: EU and Indonesia sign a trade deal
- Mexico: drug lord 'El Chapo Isidro' captured
- Sport: Verstappen wins the Las Vegas Grand Prix

Strong numbers and strong words are set large so the image still reads
at about 300px. All text is drawn programmatically; suspected or
reported items are labelled as such, with no exaggeration.

## Run

```sh
python3 main.py
```

Writes `/output/entry.png`. No network access. Running it twice
produces the same bytes.
